# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине «Конфигурационное управление»,
вариант 24.

Консольное приложение (CLI), имитирующее работу командной строки
UNIX-подобной ОС. Пользователь вводит команды в интерактивном режиме
(REPL), эмулятор разбирает их и выполняет.

## Текущий этап

**Этап 1. REPL** — минимальный прототип:

- приглашение к вводу содержит имя VFS (`vfs$ `);
- простой парсер разделяет ввод на команду и аргументы по пробелам;
- команды `ls` и `cd` — заглушки, выводят своё имя и аргументы;
- команда `exit` завершает работу эмулятора;
- обработка ошибок ввода.

## Функции

| Функция | Описание |
|---|---|
| `parse(line)` | Разбивает строку на команду и список аргументов. Для пустой строки возвращает `(None, [])` |
| `cmd_ls(args)` | Заглушка `ls`: выводит имя команды и аргументы |
| `cmd_cd(args)` | Заглушка `cd`: выводит имя команды и аргументы |
| `cmd_exit(args)` | Завершает работу с указанным кодом возврата |
| `execute(command, args)` | Ищет команду в таблице `COMMANDS` и выполняет её |
| `main()` | Главный цикл REPL |

## Команды

| Команда | Описание |
|---|---|
| `ls [args...]` | Заглушка: выводит `ls` и список аргументов |
| `cd [args...]` | Заглушка: выводит `cd` и список аргументов |
| `exit [код]` | Выход из эмулятора с кодом возврата (по умолчанию 0) |

### Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Неизвестная команда | `<команда>: command not found` |
| `exit` с нечисловым аргументом | `exit: <арг>: numeric argument required`, выход с кодом 2 |
| `exit` с несколькими аргументами | `exit: too many arguments`, эмулятор продолжает работу |
| Пустая строка / только пробелы | Игнорируется, выводится новое приглашение |
| `Ctrl+C` | Отмена текущей строки, новое приглашение |
| `Ctrl+D` | Завершение работы эмулятора |

Сообщения об ошибках выводятся в поток `stderr`.

## Запуск

Требуется Python 3.8+.

```sh
./run.sh
```

или

```sh
python3 src/main.py
```

## Тесты

Тесты написаны с использованием `pytest`.

```sh
pip install pytest
python3 -m pytest
```

Команды выполняются из папки `pract1`.

## Пример использования

```
$ ./run.sh
vfs$ ls -l /home
ls ['-l', '/home']
vfs$ cd ..
cd ['..']
vfs$
vfs$ foo
foo: command not found
vfs$ exit 1 2
exit: too many arguments
vfs$ exit abc
exit: abc: numeric argument required
$ echo $?
2
```
